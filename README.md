# DailyFlow

**DailyFlow** est une application web de gestion du quotidien conçue pour centraliser les tâches, les habitudes, le planning et le budget personnel.

## Objectifs du projet

* Organiser les tâches et les priorités.
* Planifier les activités quotidiennes.
* Suivre les habitudes et les objectifs.
* Gérer un budget mensuel.
* Visualiser sa progression grâce à un tableau de bord.

## Stack technique

* **Frontend implémenté :** Vue.js 3, TypeScript et Vite.
* **Backend prévu :** PHP avec une API REST (le dossier `backend/` est encore vide).
* **Base de données prévue :** MySQL / MariaDB (non configurée à ce stade).
* **Versionnement :** Git et GitHub.

## Architecture

* `frontend/` : interfaces utilisateur.
* `backend/` : API et logique métier.
* `docs/` : documentation technique.

## État du projet

Le frontend est en cours de développement. Il peut être lancé depuis `frontend/` avec `npm install`, puis `npm run dev`.
